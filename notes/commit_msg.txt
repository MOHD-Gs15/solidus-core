Fix Minecraft 26.1.x API breaking changes - build successful, 176/176 tests pass

API migrations required for Minecraft 26.1.x final release:

1. ResourceLocation renamed to Identifier in net.minecraft.resources
   - All "new ResourceLocation(x)" replaced with Identifier.tryParse(x)
   - All imports and type references updated

2. Entity.getServer() removed
   - player.getServer() replaced with player.level().getServer()
   - Applied across ShopManager, AuctionManager, SolidusIntegration, SellScreenHandler

3. CommandSourceStack.hasPermission(int) removed
   - New system uses PermissionLevel enum + Permission.HasCommandLevel
   - Added private hasOpLevel() helpers in PermissionChecker
   - Updated all 6 call sites in PermissionChecker

4. Component.append() only available on MutableComponent
   - Changed TextUtil builder methods to return MutableComponent
   - Changed local variable declarations from Component to MutableComponent
     where .append() is called

5. BuiltInRegistries.ITEM.get() now returns Optional<Holder.Reference<Item>>
   - Added .map(Holder::value).orElse(null) chain at all call sites
   - Affected: ShopGUI, ShopManager, ShopScreenHandler, AuctionGUI, AuctionManager

6. ItemStack.save(HolderLookup.Provider) and ItemStack.parseOptional() removed
   - Replaced with ItemStack.CODEC.encodeStart() / ItemStack.CODEC.parse()
   - Uses RegistryOps.create(JsonOps.INSTANCE, registryAccess) for serialization

7. TagParser.parseTag(String) removed
   - Replaced with JsonParser.parseString() + Codec-based deserialization

8. Lambda effectively-final variable enforcement (Java 25 strict)
   - SQLiteStorage: amount reassigned, introduced final roundedAmount
   - ShopScreenHandler.openScreen: page reassigned, introduced final safePage
   - SellScreenHandler: totalEarnings/totalItemsSold captured in final snapshots

9. CommandSourceStack.getPlayer() no longer throws CommandSyntaxException
   - Removed unnecessary try/catch in PermissionChecker.check()

10. ShopGUILayout lazy initialization
    - BORDER_PANES and ACCENT_PANES converted from static final arrays
      to lazy-initialized volatile fields with accessor methods
    - Prevents triggering Items.<clinit> (and full Minecraft Bootstrap)
      when ShopGUILayout is loaded by pure-Java unit tests

11. RateLimiter.removePlayer null check
    - ConcurrentHashMap.remove(null) throws NPE in Java 25
    - Added defensive null check

12. build.gradle fix
    - Added import for org.gradle.jvm.toolchain.JavaLanguageVersion
    - Changed LanguageVersion.of(25) to JavaLanguageVersion.of(25)
