fix(db): 5 latent bugs flushed out by the first real CI run (2.2.3)

The 2.2.2 push activated the 27 CI-gated tests for the first time
(mariadb:11 + redis:7 service containers). 4 failures came back — each a
latent 2.2.1 production bug. Reproduced locally against a portable
MariaDB 11.8.6 (no Docker: .deb-extracted mariadbd, user datadir), fixed,
re-verified, and during that verification a 5th latent bug surfaced.

Production fixes:
- Idempotent transfer replay DOUBLE-PAID: the operations claim used
  INSERT ... ON DUPLICATE KEY UPDATE with an affected-rows 1-vs-2 routing,
  but MariaDB returns 0 for a no-op duplicate update (a replay sends the
  same op_type), so replays re-executed the transfer. Claim is now
  INSERT IGNORE (1 = fresh claim, 0 = already claimed).
- Auction orphan sweep archived NOTHING on MySQL: insertSoldHistory was
  called without the dialect arg -> INSERT OR IGNORE (invalid on MariaDB)
  -> log-matched orphans were re-listed, i.e. PAID items re-entered the
  market on a network. The dialect now flows through.
- Auction search returned an empty list on MySQL: ESCAPE '\' corrupts
  statement parsing on MariaDB/MySQL (backslash is a string-literal escape
  there). Escape character is now '!' — portable on both dialects.
- Cutover migrator failed on a fresh target DB: it created only the five
  auction tables and relied on a MySqlStorage auto-create that never ran.
  Now creates the FULL target schema (MySqlStorage.createEconomySchema +
  ledger/notifications + auctions) and tolerates missing tables on old
  SQLite backups (skipped with a report note, not an abort).
- Migrator verify phase closed the shared SQLite connection via a
  try-with-resources alias (latent since 2.2.1 — masked by the copy-stage
  failure). Verify now reuses the outer connection.

Test fixes:
- MySqlAuctionDialectTest: pure-Java stubs replace Mockito entirely
  (inline mock maker cannot instrument classes OR interfaces on Java 25).
- Orphan-recovery test expectation corrected (archived history = 1, not 2;
  a re-listed orphan never settles — matches the SQLite sibling test).
- StorageMigratorTest: ConfigManager pointed at a temp dir; SQLite source
  now carries all five auction tables with real rows.

Verified locally against real MariaDB 11.8.6: 387 executions —
383 passed / 0 failed / 4 gated skips (Redis only). CI expected: 0 skips.
